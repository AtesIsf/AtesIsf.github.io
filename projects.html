RIO In progress

Sep 2026 – Present

64-bit RISC-V OS kernel in C and Assembly. Boots on QEMU's virt machine with no firmware: its own boot code configures machine mode, delegates traps, and drops into supervisor mode. Timer interrupts drive a trap dispatcher that preempts processes under a priority scheduler with context switching. Processes synchronize with semaphores and sleep on a delta queue, and memory comes from a bitmap-based page allocator that hands out contiguous multi-page regions. A bare-metal test suite runs headless under QEMU and powers the VM off when done.

~2,000 lines (~2,900 with tests) · 8 test suites, one per subsystem

Stack: C, Assembly, QEMU, Docker/Podman

Monetary-Sim

May 2026 – Jun 2026

Agent-based simulation of monetary policy in Go. Goroutines parallelize 10,000+ agents for a 1.65x speedup over a sequential run. Thread-safe ledger and bank guarded by mutexes, verified by money-conservation invariant tests. Buffered CSV recording with pandas/Matplotlib visualizations.

Stack: Go, Python

chat-cli

Oct 2025 – Mar 2026

Peer-to-peer CLI chat in C with direct TLS messaging; the lookup server only handles peer discovery and never relays messages. Lookup server built on Berkeley Sockets with an open-addressed hash table. Trust-on-first-use (TOFU) peer authentication pinning SHA-256 certificate fingerprints in SQLite.

Stack: C, OpenSSL, SQLite, Docker
